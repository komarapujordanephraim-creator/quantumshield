# QuantumShield product walkthrough

[Watch or download the 42-second narrated demo](QuantumShield-Product-Demo-v2.mp4).

The video uses actual QuantumShield v0.5.0 results from a synthetic three-file repository: RSA usage, an MD5 pattern and a JWT dependency. The animated workspace is an illustrative UI concept, not a recording of a shipping desktop application.

The scanner supports source/config discovery, dependency checks, and JSON, SARIF and HTML reports. Findings need validation in context; a clean scan does not prove quantum safety.

The narration is synthetic English speech; the background score is original synthesized music.
